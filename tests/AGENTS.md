# tests 说明

适用范围：`tests/`。同时遵守根 `AGENTS.md`；实现契约见 `src/AGENTS.md` 与 `client/AGENTS.md`。

- 在宿主 external 副本运行 Vitest；不在源码目录安装依赖。单元套件不请求公网服务、不读取真实聊天数据。
- 工具测试使用真实 Cordis、Satori Session、Permissions 与 Tools 服务；消息边界可替换，但不得用自造执行器替代 `ctx.tools.execute`。结束循环必须断言执行记录的原生 `ends`，不把播放器内部 `endTurn` 或结果文本等同于原生结束标记；卡片成功结果仍为文本。
- 网络测试用本地 HTTP 服务器，覆盖搜索竞速/空结果/部分失败、Meting 解析、超时和取消。插件生命周期测试加载真实入口和 Cordis Server，验证只注册工具、不注册重定向路由；模型链接回归检查原始 URL 和签名参数不被改写。
- 模型链接提示的回归覆盖候选、选歌、单曲与 AI 临时切换，并核验用户显式文件/链接要求优先于默认音频；提示出现不能等同于模型实际按提示发送成功。
- UI 测试挂载真实 SchemaForm/ui-kit 和 LocaleService；DOM 测试不能代替浏览器的布局、焦点和音频解码验收。
- OneBot 联调使用新建测试空间，覆盖 NapCat/LLBot/SnowLuma、群/私聊与卡片/模型链接两种模式。以原始出站 payload 和目标会话断言卡片，不要求沙箱渲染它未支持的音乐富卡片；配置回归验证已移除模式直接校验失败，不自动转换；不能把 ChatLuna 后续发送当成插件直发。
- 默认完成或失败测试空间并保留证据，不删除主环境、真实预设或用户凭据。临时宿主、服务器和浏览器会话必须关闭；预览服务可保留并给出实际局域网地址。
- 根说明登记所有子目录 AGENTS.md，并由守卫测试验证。
