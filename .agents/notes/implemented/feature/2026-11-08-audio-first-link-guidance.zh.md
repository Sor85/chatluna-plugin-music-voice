# Agent Note: Audio-first model link guidance

Status: implemented

## Problem

模型链接模式返回可用地址，但原有说明没有定义用户未指定发送形式时的优先行为，模型可能只发送链接文本。

## Decision

共享 MODEL_LINK_DELIVERY_HINT 提示默认优先使用原始链接发送音频，用户明确要求文件或链接时遵从其要求，音频无法发送时回退原始链接。模型链接模式的候选和单曲结果均包含提示；允许该模式的工具定义及中文描述也包含同一提示，包括 AI 临时切换场景。

## Alternatives considered

仅在工具描述中增加提示可能受宿主元数据覆盖影响；只在候选结果增加会遗漏单曲和直接传入序号的场景。共用提示覆盖这些入口，不新增插件发送分支。

## Consequences

插件仍然只返回原始链接，不下载、不发送、不设置 ends，也不改变保存的模式。提示是模型行为指导，不是音频发送成功的保证；真实发送与失败处理由 ChatLuna 执行。原生工具回归覆盖提示内容、各入口及无发送副作用。
